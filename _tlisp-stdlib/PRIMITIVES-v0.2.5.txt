# tatara-script primitives — the list CI actually has
#
# Extracted from tatara-lisp `register_fn` sites at tag v0.2.5, which is what
# `tatara-script/action.yml` pins. 115 names, 2026-08-06.
#
# WHY THIS FILE EXISTS. A survey of every shell site in this repo classified 23
# of them as "needs a decision, no primitive exists". Most of those calls were
# wrong: chdir, cwd, now, now-ms, now-rfc3339, yaml-parse, file-size, walk-dir,
# path-join, mkdir-p, json-stringify, http-post-json and re-captures ALL exist.
# The mistake was probing SCHEME spellings — substring, string-ref,
# string->list — finding them absent, and generalising "there is no slicing /
# chdir / clock primitive". A naming miss, not an absence. It sent work toward
# building primitives that were already there.
#
# So: check here before concluding anything is missing. The absent names really
# absent are the Scheme ones (substring, string-slice, string-ref, string->list,
# string-prefix?, string-suffix?, cadr, string->number) plus shell-quote and
# which. Each of those was invented by some author and shipped broken.
#
# NOT IN v0.2.5 but present at tatara-lisp HEAD: exec-with-env, exec-with-stdin.
# That is load-bearing — anything needing to pipe stdin to a tool must use the
# tool own file-operand form until the pin moves.
#
